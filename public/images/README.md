# Portfolio image sources

- `studio-sculpture.webp`: original AI-generated studio artwork created for this redesign.
  Decorative composition, not a photograph of a Dovindustries product or prototype.
  Generated October 7, 2026; optimized from the original raster output.
- `bear-mark.webp`: optimized from the existing Dovindustries black bear logo.
- `simplysefer-marketplace.webp`: browser capture of the existing Simply Sefer homepage,
  October 7, 2026. Shows public marketplace content; not an invented product interface.

Image optimization helper: `node scripts/optimize-image.mjs input output [width]`.

`art-studio.webp`, `art-movement.webp`, and `art-painted-forms.webp` are original
generated oil-painting studies for the /art-direction comparison page.
`art-studio-v2.webp` refines the studio around actual portfolio themes after a relevance review.
These depict imagined scenes and concept objects, not built products or a real studio.

`art-bear-study.webp` is a focused oil-and-charcoal study developed from the existing
bear identity and the concept of revising one drawing element. It is an original
generated illustration, not a replacement logo or evidence of a functioning AI edit.

`art-bear-sketch.webp` and `art-bear-paw-edit.webp` are generated variations of the
bear painting for a concept sequence. The first shows a charcoal stage; the second
lifts one front paw. The UI clips the edit to that region. These are illustrative
frames, not drawing-model outputs. All study images were generated October 7, 2026.
