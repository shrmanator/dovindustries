# Portfolio redesign

## Brief

Exceptional finish informed by OpenAI, Anthropic, and Work Louder.
Work Louder adds tactile product imagery and confident, varied composition to the brief.
Plain, specific copy; distinctive imagery; calm hierarchy; excellent responsive behavior.
The subject is an independent portfolio of live software and emerging research.

## Direction

An open, light studio space with a sculptural image as the memorable element.
Avoid repeating dark feature-card grids, giant all-caps slogans, decorative technical chips,
or cream-and-orange styling copied from a reference brand.

Palette: porcelain #f8f9fa, graphite #20242b, white #ffffff, cobalt #344cf4,
glacier #e6eef3, slate #667078. Cobalt lives primarily in the artwork.
Type: DM Sans for legibility and warm geometric character. Instrument Serif for the
compact research feature heading, giving that section its own editorial rhythm.
Layouts are left aligned, with deliberate changes in scale rather than identical cards.

## Structure

Header: bear mark and name / Work / Research / Contact.
Hero: clear studio scope / concise description / full-width original sculpture.
Work: two live products with a real marketplace view and an illustrative donation flow.
Research: one substantial Vibe Draw concept illustration, two compact research entries.
History: a short SuperMint note and accurately named original-site link.
Footer: direct contact, GitHub, and copyright.

## Review against the brief

The first instinct was another black portfolio with oversized display slogans.
That repeated the original site's weaknesses. The revised plan uses light surfaces,
one image-led composition, and content-specific layouts instead.
An illustration is labeled as a concept, never presented as a working product demo.
Unverified accuracy, latency, acceleration, and release promises are omitted.
There is no fake application interface, invented customer proof, or mock checkout.

## Quality targets

Server-rendered content; small client islands only for navigation and concept controls.
No autoplay video, animation library, or recurring scroll reveals.
Optimized local imagery with intrinsic dimensions and responsive sizes.
Accessible controls, readable contrast, visible focus, and reduced-motion support.
Desktop, tablet, 390px, and 320px visual and interaction checks.
Production build and measured Lighthouse run; report actual results and limitations.
Every authored source file below 300 lines; shared layout styles split by responsibility.
